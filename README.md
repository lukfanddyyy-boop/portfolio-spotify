## 🚀 Cara Menggunakan

### **Opsi 1: Clone Repository**

```bash
git clone https://github.com/lukfanddyyy-boop/portfolio-spotify.git
cd portfolio-spotify
```

Lalu buka file `index.html` di browser.

### **Opsi 2: Download ZIP**

1. Klik tombol **"Code"**
2. Pilih **"Download ZIP"**
3. Extract dan buka `index.html`
